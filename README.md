# Fer AL - Plataforma de Feiras e Eventos Culturais de Alagoas

Projeto desenvolvido para o Projeto Integrador VI-A 2026.2, do curso de Análise e Desenvolvimento de Sistemas do Centro Universitário Cesmac.

O objetivo é criar uma plataforma web voltada para a gestão e visualização de feiras, com sistema de cadastro e notificações.

Para escopo e não escopo do projeto, verifique ESCOPO.pdf.
